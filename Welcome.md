# Welcome to the Online Workshop on Global Tools for Flood and Drought Prediction

This repository is created for the interactive session of the WMO online workshop on Global Tools for Flood and Drought Prediction.
It features three Jupyter Notebooks that we will explore during today's session:

* Accessing and Downloading GloFAS Data from the CEMS Early Warning Data Store (EWDS)

* Download GloFAS Seasonal Forecast using the API

* Download and plot seasonal forecast using earthkit

These notebooks are designed to provide hands-on experience with accessing, working with, and understanding GloFAS seasonal forecasts .
